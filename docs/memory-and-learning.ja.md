# shikiiとメモリーの違い

**「前に話したことを覚える」という部分は共通しています。shikiiは、その記憶を仕事で使い、役立ったかを振り返り、人の答えをもとに判断の任せ方も調整する仕組みです。** 同じ説明や訂正を繰り返す負担を減らし、プロジェクトに合う働き方を育てることを目指しています。

たとえば「説明書を直す時は、日本語版と英語版を一緒に直して」と伝えた場合、覚えておくだけでは、その後も両方を直したかは分かりません。shikiiでは、この決まりを出典付きの記事にして、関係する仕事で届けます。実際に役立ったかをエージェントが振り返り、機械で確認できる部分は、人が有効にした検査で確かめられます。

## OpenAIのメモリーとは重なる部分もある

OpenAIの公開説明では、メモリーは好みだけでなく、繰り返す作業やプロジェクトの慣習など、以前の会話の文脈を次の仕事へ持ち越すものです。ChatGPTのメモリーと、Codexのローカルメモリーは別の保存先と設定を持ちます。Codexのローカルメモリーには、以前の会話に基づく要約や出典となる情報も含まれます。[OpenAIのメモリーの説明](https://learn.chatgpt.com/docs/customization/memories)、[パーソナライズの説明](https://learn.chatgpt.com/docs/personalize)

そのため「OpenAIは好みしか覚えない」「shikiiだけがローカルに保存する」という分け方は正確ではありません。ここで比べているのはメモリー機能の公開説明です。OpenAI製品全体の指示・ツール・権限管理との比較ではありません。

| 見るところ | メモリーでできること | shikiiが組み合わせること |
| --- | --- | --- |
| 前の仕事を次に生かす | 過去の文脈を思い出す | プロジェクトの知識を、適用条件・理由・出典付きで残す |
| 必要な時に使う | 次の会話や仕事の参考にする | 依頼の前やファイル操作の直前に、関係する記事を届ける |
| 記憶を手入れする | メモリーを管理する | 役立った・使わなかった・害があったという振り返りを、届け方と記事の見直しに使う |
| 判断を任せる | 文脈を踏まえて回答する | 人の答えや確認できた結果を集め、AIだけで決めてよい範囲を測る |
| 必要な作業を確かめる | 必須の指示は別途管理する | 有効な検査と、必要な記録の保存確認を組み合わせる |

OpenAIも、必ず適用するチームの指示は `AGENTS.md` や管理された文書に置き、メモリーだけに頼らないよう案内しています。[OpenAIのメモリーの説明](https://learn.chatgpt.com/docs/customization/memories)

## shikiiでは、経験が次の仕事へ戻る

1. **残す。** 人が伝えた目的、選んだ方針、訂正、確かめた結果を、プロジェクトの `.shikii/` に保存します。記事には「どんな時に使うか」と出典があり、後から理由を確かめられます。
2. **届ける。** 仕事の始めや関係する操作の前に、必要な知識をエージェントへ渡します。関連する判断基準も参照できます。同じプロジェクトに接続したClaude Code・Codex・OpenCodeが共有できます。
3. **振り返る。** エージェントは、届いた記憶が実際の行動にどう影響したかを記録します。単に届いたことや、仕事が成功したことだけを「役立った」とは数えません。
4. **手入れする。** 使われない記事や害があった記事は、出典を確認して見直します。同じ条件で繰り返し使われなかった記事は、その場面への自動配信を控えます。人も知識画面から記事を編集・削除できます。
5. **任せ方を調整する。** 繰り返す判断について、人の答えや確認できた結果とAIの予測を比べます。十分な記録と品質がある場合に、AIだけで決める範囲と人に確認する範囲を設定します。

この二つの循環、**「知識を使って手入れする」ことと「判断を測って任せ方を変える」こと**が、shikiiの中心です。ここで育つのはプロジェクト側の知識と判断基準で、AI本体の重みを書き換える学習ではありません。

## 何を確かめたと言えるのか

振り返りはエージェントの仮の評価です。人の正解や、性能が上がったという実測値とは分けて保存します。記憶をたくさん読んだことだけでは、仕事が良くなった証拠になりません。

検査にも範囲があります。たとえば「日本語版と英語版を一緒に変更したか」は機械で調べられますが、両方の文章が十分に分かりやすいかまでは保証しません。0.14.1では、必要な計画整理や振り返りが未保存なら具体的な修復手順を返し、保存が進んだかを確認するようになりました。進展がない時や確認に失敗した時は、未完了として自動継続を止めます。

知識やAIの判断は、操作の許可を与えるものでもありません。今回の依頼と、使っているエージェントの権限ルールが優先されます。
